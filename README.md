# PetVesta Landing

The Gold Standard of Bespoke Pet Care – marketing landing page.

## Deploy to Vercel

1. **From the repo (recommended)**  
   - Push this project to GitHub/GitLab/Bitbucket.  
   - Go to [vercel.com](https://vercel.com) → **Add New Project** → import the repo.  
   - Leave **Build Command** and **Output Directory** as default (no build; root is the output).  
   - Click **Deploy**.

2. **From the CLI**  
   - Install the Vercel CLI: `npm i -g vercel`  
   - In this directory run: `vercel`  
   - Follow the prompts and deploy.

The site is static (single `index.html`; Tailwind and GSAP from CDN). No build step is required.
